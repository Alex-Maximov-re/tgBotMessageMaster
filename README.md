# Уведомления Авито в Telegram

Бот присылает в Telegram письмо Авито о новом сообщении. Для этого варианта тариф и API Авито не нужны: программа читает ваш почтовый ящик по IMAP.

Письмо появляется не мгновенно: Авито отправляет его со своей задержкой, бот проверяет ящик раз в минуту. В чат на Авито бот ничего не пишет.

## Почта

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
```

В `.env` заполните `IMAP_USER`, `IMAP_PASSWORD`, `TELEGRAM_BOT_TOKEN`. Для Яндекса, Mail.ru, Gmail и Outlook `IMAP_HOST` можно не указывать. В `IMAP_PASSWORD` нужен пароль приложения: его включают в настройках почты вместе с доступом по IMAP.

В Авито включите уведомления о сообщениях на этот же ящик: профиль → настройки → уведомления.

Напишите своему боту любое сообщение и выполните:

```powershell
python -m app mail-check
```

Команда входит в почту и печатает последние письма Авито. Строка `[уведомление]` уйдёт в Telegram, `[пропуск]` — нет. Если нужное письмо помечено как пропуск, поставьте `MAIL_ACCEPT_ALL=true`. Если `TELEGRAM_CHAT_ID` пуст, команда покажет id чата. Впишите его и запустите `mail-check` ещё раз: в Telegram придёт проверочное сообщение.

Дальше держите программу запущенной:

```powershell
python -m app mail
```

Письма, которые уже лежали в ящике, при первом запуске не пересылаются. Чтобы получить и их, поставьте `MAIL_NOTIFY_EXISTING=true`. Повтор одного письма не шлётся: id хранятся в `data/state.json`. Письма в ящике остаются непрочитанными.

## API Авито

Второй вариант — официальный вебхук мессенджера. Нужен платный тариф с API и ключи из раздела [Для профессионалов → API](https://www.avito.ru/professionals/api). Документация: [developers.avito.ru](https://developers.avito.ru/api-catalog/messenger/documentation).

## Ключи API

Заполните `.env`: `AVITO_CLIENT_ID`, `AVITO_CLIENT_SECRET`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `WEBHOOK_SECRET`. Секрет — длинная строка из латинских букв и цифр.

Узнать чат Telegram:

1. Напишите своему боту любое сообщение.
2. Запустите `python -m app check`.
3. Если `TELEGRAM_CHAT_ID` ещё пуст, команда напечатает его. Впишите в `.env` и запустите `check` ещё раз: в чат придёт проверочное сообщение, а в консоли будет `user_id` Авито.

## Как получать сообщения

Авито стучится только на публичный HTTPS. На своём компьютере это туннель, например Cloudflare:

```powershell
cloudflared tunnel --url http://127.0.0.1:8080
```

В `.env` запишите выданный адрес без пути в `PUBLIC_BASE_URL`, например `https://xxxx.trycloudflare.com`. В одном окне держите сервер:

```powershell
python -m app
```

Если адрес туннеля появился уже после старта, регистрацию можно сделать отдельно, не останавливая сервер:

```powershell
python -m app subscribe
```

`subscribe` отправляет в Авито `POST /messenger/v3/webhook`. Сервер отвечает на `/avito/webhook` сразу, а сообщение в Telegram уходит следом. Свои исходящие не пересылаются. Повтор того же сообщения не шлётся: id хранятся в `data/state.json`.

Пока туннеля нет, можно опрашивать непрочитанные чаты. В `.env` поставьте `POLL_INTERVAL_SECONDS=30` и `SUBSCRIBE_ON_START=false`, затем `python -m app`. Уже лежащие старые непрочитанные при первом проходе не шлются. Чтобы получить и их, поставьте `POLL_NOTIFY_EXISTING=true`.

Опрос видит только то, что ещё не прочитано в Авито. Вебхук приходит и на прочитанные сразу сообщения, поэтому для постоянной работы лучше туннель.

## Что придёт в Telegram

Текст, имя автора и объявление, если Авито отдал карточку чата. Картинка, звонок, файл или видео без текста приходят как пометка вида `[изображение]`. Ссылка «Открыть чат» ведёт в мессенджер профиля.

## Если Авито отвечает ошибкой

`python -m app check` показывает код. `401` на токене — неверные ключи. `403` на мессенджере — у тарифа нет этого API. Ключи и тариф заводятся в кабинете Авито, не в этом репозитории.
